AIマップはじめの一歩
まわりではAI・Webサービスがどう活用されているのかを、会社や組織に所属していなくても、わかりやすく説明していきます。
AIの動向毎週更新サービス図鑑目的や連携で探す使い方を学ぶ最初の準備から注意点まで
最初の7日間最初の準備テンプレ集AIと向き合うために実務のコツ
1日10分、毎日ひとつ試してみよう。時間があるなら、一気に進めてもかまいません。
0 / 7日
1日目約10分
データの設定と、AI用フォルダを決める
AIに仕事を渡す前に、入力した内容が学習に使われるかを、設定で確かめます。
  1. 使うAIの「学習に使う」設定を見る
  2. AIに見せていいものだけを入れる、専用フォルダを1つ作る
最初の準備を見る →
2日目約10分
AIに、自分の仕事を渡す
最初に仕事の説明を渡しておくと、あとの返事が自分向けになります。
  1. 屋号・仕事の内容・よくあるお客さんを、3行で書く
  2. 下の文をAIに貼って、頼む
  3. 出てきた文を、自分の言葉に直す
AIに貼る文
次の内容をもとに、私の仕事を30字で説明してください。
屋号:[あなたの屋号]
仕事:[仕事の内容]
お客さん:[よくあるお客さん]
お客様の名前や連絡先は書かなくて大丈夫です。仕事の説明だけで足ります。
3日目約10分
メールの返信案を作る
問い合わせに、まず返事の下書きを作ってもらいます。送る前に、必ず自分で読みます。
テンプレを見る →
4日目約10分
見積書の文面を整える
金額や相手の名前は、AIに渡さず、文面だけ頼みます。
5日目約10分
打ち合わせメモを整理する
走り書きのメモを、決まったこと・やること・次の予定に分けてもらいます。
6日目約10分
調べものを、出典つきで頼む
調べた内容は、出典のリンクを付けてもらい、数字や固有名詞は自分で出典を開いて確かめます。
7日目約10分
自分の使い方を1つ決める
7日間で試した中から、続けるものを1つだけ決めます。決めたら、「AIと向き合うために」を一度通します。
AIと向き合うために →
「できた」の印は、このブラウザの中だけに保存されます。ほかの端末や、ブラウザのデータを消した後には引き継がれません。
時間は目安です。
