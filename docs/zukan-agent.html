Claude(Cowork・Claude in Chrome)
公式ページ
できること
やりたいことを伝えると、ファイルの作成・編集、つないだアプリの操作、サイトを開いてのクリックや入力まで、Claudeが進めます。作業はクラウドで動き、スケジュール実行はパソコンが起きていなくても動きます。Claude in Chromeでは、自分のログイン状態のまま、Chromeでの作業を任せられます。
公式ページ
承認
Coworkには3つのモードがあります。毎回確認する「Manual」、Claudeが安全確認をしながら進める「Auto」、確認なしの「Skip」です。ファイルの完全な削除は、必ず許可が必要です。
公式ページ
条件
有料プラン(Pro・Max・Ultra・Team・Enterprise)が対象です。Enterpriseは管理者が有効にします。パソコンの画面を操作する機能は、Pro・Max・Ultraのベータ版です。Claude in ChromeはChrome専用で、他のChromium系ブラウザやモバイルは未対応と書かれています。
確認できず
日本
日本での提供について、今回見たヘルプには地域の制限は書かれていませんでした。日本を名指しした記載も、確認できませんでした。
確認元

Claudeのヘルプ:Claude in Chromeをはじめる
Claudeのヘルプ:パソコンを使わせる(Cowork)

Microsoft Copilot(Word・Excel・PowerPointのエージェント、Copilot Actions)
公式ページ
できること
Copilotの中で、Word・Excel・PowerPointのファイルを、エージェントがつくります。パソコンのアプリやファイルを操作する「Copilot Actions」は、Windows Insider向けの試験提供(Copilot Labs)として案内されています。
公式ページ
承認
Copilot Actionsは、設定の「試験的なエージェント機能」をオンにしたときだけ動きます。既定ではオフです。エージェントは専用のアカウントと、分けられた作業領域で動きます。

条件
Word・Excel・PowerPointのエージェントは、有料のMicrosoft 365 Copilotライセンスが必要です。さらに、Anthropicのモデルを管理者が有効にしている必要があります。Copilot Actionsの案内ページは更新が古い(約1年前)ので、今の状況は公式ページで確認してください。

Muse(Meta)
公式ページ
できること
目標を伝えると、計画を立てて作業を進める「パーソナルAIエージェント」です。アプリを閉じたあとも作業を続けます。Gmail・Googleカレンダー・Instagramなどとつなげます。ブラウザを開いてフォームに入力することもできる、と書かれています。
公式ページ
承認
メールの送信や商品の購入など、重要な操作の前に、本人に確認します。パスワードや支払い方法は確認できない、と書かれています。行った操作の履歴も見られます。
公式ページ
条件
多くの基本機能は無料で、有料のサブスクもあります。公式ヘルプには、無料は利用上限つきとあります。金額は、公式ページでは確認できませんでした。サブスクは18歳以上が対象です。
