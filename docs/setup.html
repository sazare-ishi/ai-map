2. AI用の専用フォルダ
おすすめの使い方(やり方の提案): AIに見せていいものだけを入れるフォルダを1つ作り、AIには、そのフォルダの中のものだけを渡します。契約書・個人情報・パスワードは、入れません。
Claude
パソコン
確認元:公式ページ Claude Desktopで接続したフォルダだけを、読み書きできると書かれています。接続したフォルダは、設定の「Trusted folders」に出ます。
Googleドライブ
確認できず つなぐと、Claudeは自分のGoogleアカウントで見られる範囲を検索して読めます。「このフォルダだけ」に絞る設定は、公式ページに書かれていません。渡す範囲を絞りたいときは、下の「3. ファイルの渡し方」のとおり、チャットに直接つける方法もあります。
条件
パソコンのフォルダは、Claude Desktop(Mac・Windows)を開いている間だけ使えます。
確認元: Get started with Claude Cowork / Claude Cowork and chat are one Claude / Use Google Workspace connectors
ChatGPT
Googleドライブ
確認元:公式ページ つなぐと、ライブラリにフォルダが出て、フォルダを選んで「中のファイルをまとめて」頼めます。
範囲
確認できず 見えるのは、自分のドライブと、自分に共有されたものです。個人で「このフォルダだけ」に絞る設定は、公式ページで確認できませんでした。プロジェクトでは、Googleドライブのファイルやフォルダのリンクを貼って、情報源に足せます。
管理者
条件あり 会社などの管理者向けには、共有ドライブ単位で許可・ブロックができます。フォルダ単位の制限はできないと書かれています。
確認元: Using Library to manage files in ChatGPT / Managing Google Drive access in ChatGPT / Projects in ChatGPT
Gemini
Googleドライブ
確認元:公式ページ 「ドライブから追加」で、ファイルを選んで渡せます。1回に最大10ファイルです。
条件
「アクティビティの保存」をオンにして、Google Workspaceを接続する必要があります。
ドライブ内
条件あり Gemini in ドライブでは、フォルダを選んで要約できます。ただし、対象のGoogle Workspaceプランか、Google AIのプランが必要です。フォルダは一度に1つまでで、中のすべてのファイルが含まれるとは限りません。
確認元: ファイルをアップロードして分析する / Gemini in ドライブでファイルの更新と概要を取得する
Microsoft Copilot
フォルダ
確認できず 個人のMicrosoftアカウントでは、OneDriveやGoogleドライブをつなぐと、見られる範囲のファイルを探せます。フォルダ単位で絞る設定は、公式ページに書かれていません。
確認元: Connecting Microsoft Copilot to other services
3. ファイルの渡し方:チャットに直接つける/コネクタでつなぐ
渡し方は2通りあります。チャットに直接つけるは、選んだファイルだけをその会話に渡す方法です。コネクタでつなぐは、GoogleドライブなどのアカウントとAIをつなぎ、AIが自分の見られる範囲から探して読む方法です(公式ページには、つないだ先で自分が見られないものはAIも見られない、と書かれています)。渡す範囲をはっきりさせたいときは、直接つけるほうが分かりやすい、というのがおすすめの使い方(やり方の提案)です。ボタンの名前や場所は変わるので、画面と違うときは公式ページを見てください。
Claude
直接つける
確認元:公式ページ チャット欄の「+」→「Add files or photos」で、パソコンのファイルを選びます。1つのチャットに、最大20ファイルまでです。PDF・DOCX・CSV・TXT・画像などが使えます。XLSXは、設定でコード実行とファイル作成をオンにする必要があります。日本語の表示名は確認していません。
コネクタ
確認元:公式ページ 「+」のメニューでコネクタをオン・オフします。初回はGoogleのサインイン画面に移ります。「+」→「Add from Google Drive」で、最近のファイルから選ぶか、URLを貼って追加できます。
範囲
確認できず つないだGoogleアカウントで見られる範囲が対象です。「このフォルダだけ」に絞る方法は、公式ページに書かれていません。
注意
確認元:公式ページ Googleドライブのファイルの共有・移動・ゴミ箱への移動は、「Auto」モード以外では、実行前に確認が出ると書かれています。Team・Enterpriseでは、先に管理者がコネクタをオンにします。
確認元: Upload files to Claude / Use Google Workspace connectors / Use connectors to extend Claude's capabilities
ChatGPT
直接つける
確認元:公式ページ 入力欄の添付ボタンから、対応するファイルをつけます。1ファイル最大512MB、文書は1ファイル200万トークン、画像は1枚20MBまでです。1回につけられる数は、プランや画面で違います。
保存
確認元:公式ページ つけたファイルは「ライブラリ」に保存され、次からは「Add from library」で選べます。一時チャットでつけたファイルは、一時チャットのあいだは保存されません。
コネクタ
確認元:公式ページ 「Plugins」か「Apps」から、Googleドライブをつなぎます。つなぐと、ライブラリでドライブのファイルを選べます。入力欄から呼び出す、@メンションで追加する、フォルダを選んで「中のファイル全体で」頼む、もできます。
範囲
確認元:公式ページ つないだGoogleアカウントで見られるファイルが対象です。ファイルを追加しても、Googleドライブ側の共有設定は変わりません。
確認元: Uploading files and audio to ChatGPT / Using Library to manage files in ChatGPT / Google Drive app and setup in ChatGPT / Google app data controls FAQ
Gemini
直接つける
確認元:公式ページ パソコンでは、入力欄の「ファイルを追加」→「ファイル」で、デバイスのファイルを選びます。スマホでは、追加のアイコンからファイル・フォト・カメラを選べます。
ドライブ
確認元:公式ページ 「ファイルを追加」→「Google ドライブ」で、ドライブのファイルを選びます。「アクティビティの保存」をオンにして、Google Workspaceを接続する必要があります。接続されていないときは、接続する案内が出ます。
仕事・学校
条件あり 仕事用・学校用のアカウントでは、ドライブから追加するには、組織の管理者が、Geminiでアプリの使用を有効にする必要があります。
確認元: ファイルをアップロードして分析する(パソコン) / ファイルをアップロードして分析する(Android)
Microsoft Copilot
直接つける
確認できず 個人のMicrosoftアカウントで、チャットにファイルを直接つける方法は、今回の公式ページでは確認できませんでした。
仕事・学校
確認元:公式ページ 仕事用・学校用のCopilot Chatでは、「画像とファイルをアップロード」でデバイスのファイルを、「クラウドファイルを添付」でOneDriveのファイルを選べます。
コネクタ
確認元:公式ページ 個人のMicrosoftアカウント(Microsoft 365 Personal・Family・Premium・Pro)では、Copilotの「プロフィール」→「Connectors」から、OneDriveやGoogleドライブなどをつなぎます。copilot.comの「+」→「Use connectors」で、オン・オフします。ファイルは、名前・種類・最近の使用状況で探せます。
条件
確認元:公式ページ OneDriveとOutlook.comは、Copilotで使っているMicrosoftアカウントと、同じアカウントでないと内容を取得できません。
確認元: Connecting Microsoft Copilot to other services / Microsoft Copilot Chat プロンプトにコンテンツを追加する
