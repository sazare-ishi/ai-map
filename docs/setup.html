AIマップはじめの一歩
まわりではAI・Webサービスがどう活用されているのかを、会社や組織に所属していなくても、わかりやすく説明していきます。
AIの動向毎週更新サービス図鑑目的や連携で探す使い方を学ぶ最初の準備から注意点まで
「AIの動向」の色も、この区分です。やりたいことの役割から、サービスを選べます。
最初の7日間最初の準備テンプレ集AIと向き合うために実務のコツ
AIに仕事を渡す前に、データの使われ方と、見せる範囲を決めます。
ここに書くのは、各社の公式ページで確認できたことだけです。設定の名前や場所は変わるので、画面と違うときは公式ページを見てください。オフにするのは「これからの会話」が対象で、すでに使われた分は戻りません。
1. 入力した内容を、学習に使わせない設定
ChatGPT
場所
確認元:公式ページ 設定 → データコントロール →「すべてのユーザーのためにモデルを改善する」をオフ。
注意
個人のFree・Plus・Proは、初期設定で共有がオンです。オフにしても、チャットの履歴は残ります。
別の手
「一時チャット」は、履歴に残らず、メモリも作らず、学習にも使われません。安全のため30日は保持されます。
確認元: Data controls in ChatGPT / How ChatGPT learns about the world while protecting privacy

注意
オンにすると、データを最長5年保持すると公式に書かれています。オフなら、保持は30日です。
確認元: How do I change my model improvement privacy settings? / How long do you store my data?
Gemini
場所

オフでも、会話は最長72時間は保存されます。「一時チャット」は、学習に使われないと書かれています。

確認元: Gemini アプリのプライバシー ハブ / ファイルをアップロードして分析する
Microsoft Copilot
場所
確認元:公式ページ copilot.com・Windows/macOS・モバイルアプリで、プロフィール → プライバシー →「会話アクティビティのトレーニング」と「音声会話のトレーニング」をオフ。
注意
オフにしても、個人用設定(記憶)は使えます。オフでも、製品改善・広告・安全などの目的の利用は、この設定では止まらないと書かれています。

2. AI用の専用フォルダ
おすすめの使い方(やり方の提案): AIに見せていいものだけを入れるフォルダを1つ作り、AIには、そのフォルダの中のものだけを渡します。契約書・個人情報・パスワードは、入れません。
Claude
パソコン
確認元:公式ページ Claude Desktopで接続したフォルダだけを、読み書きできると書かれています。接続したフォルダは、設定の「Trusted folders」に出ます。
Googleドライブ
確認できず チャットやプロジェクトに、ファイルを選んで追加できます。使うのは、自分のGoogleアカウントで見られる範囲です。「フォルダだけに絞る」設定は、公式ページで確認できませんでした。
条件
パソコンのフォルダは、Claude Desktop(Mac・Windows)を開いている間だけ使えます。
確認元: Get started with Claude Cowork / Claude Cowork and chat are one Claude / Use Google Workspace connectors
ChatGPT
Googleドライブ
確認元:公式ページ つなぐと、ライブラリにフォルダが出て、フォルダを選んで「中のファイルをまとめて」頼めます。
範囲
確認できず 見えるのは、自分のドライブと、自分に共有されたものです。個人で「このフォルダだけ」に絞る設定は、公式ページで確認できませんでした。
管理者
条件あり 会社などの管理者向けには、共有ドライブ単位で許可・ブロックができます。フォルダ単位の制限はできないと書かれています。
確認元: Using Library to manage files in ChatGPT / Managing Google Drive access in ChatGPT
