内容
仕事用のMicrosoft Copilotに、「Slack for Copilot」というプラグイン(AIに機能を足す追加部品)があり、Copilotが、Slackのチャンネル・ダイレクトメッセージ・スレッド・共有ファイルを検索できる、とMicrosoftの公式ページにあります。
つなぎ方
Copilotの画面からつなぐ連携: Microsoftのページ(AI側)に、Slackのプラグインの案内があります。Slack側のページ(サービス側)で、SlackのMCPサーバーを使えるAIとして挙がっているのは、Claude・Perplexity・Cursorなどで、Copilotの名前は載っていません。
自分で組み込む方法: Slack側の開発者向けページ(サービス側)に、SlackのMCPサーバー(AIが外のサービスとつながるための共通の決まりにそった窓口)の説明があります。
条件・注意
Microsoftのこのページは、Copilot Coworkのプラグイン一覧のものです。仕事用の仕組みで、組織側の設定が関わります。ほかに、パートナー企業が作ったSlackのコネクタ(AIとサービスをつなぐ部品)も、Microsoftの一覧にあります(提供元ごとに、サポートの形が違うと書かれています)。個人向けのCopilotで使えるかは、確認できませんでした。Slack側の開発者向けページ(サービス側)には、MCPを使えるのは、Slackのアプリ一覧に載っているアプリか、自社用のアプリだけで、ワークスペースの管理者が承認と管理をする、と書かれています。
確認元
AI側Microsoft Learn:Copilot Coworkで使えるプラグイン
AI側Microsoft Learn:パートナー製コネクタの一覧
サービス側Slack:SlackのMCPサーバーの概要
サービス側Slackのヘルプ:SlackのMCPの手引き
分からないときは、自分のAIに確認元の公式ページを読ませて、「公式ページに書かれていないことは、書かれていないと答えて」と頼んでみてください。判定は、サービス側の公式ページに書かれていることで決めています。書かれていない=できない、ではありません。料金・機能は変わるので、最後は公式ページで確認してください。
