AIマップ
会社や組織に入っていなくても、まわりの人がどんなAI・Webサービスを、どう使っているかが見えるページを目指しています。
最近の変化AIサービスの動きサービス図鑑目的から選ぶ運用のコツ使い続けるときの注意
運用のコツ
使い続けるときに、手間が減るところと、つまずく点。
公式ページ
YouTube Studio + 公開予約
できること
動画を先にアップして、公開する日時を決めておけます。
費用
YouTube Studioの機能で、追加のツールは要りません。
つまずき
コミュニティガイドラインの警告を受けた期間は、予約した動画が公開されません。
公式ページ
YouTube Data API + 自動投稿
できること
プログラムから、動画を自動でアップロードできます。
費用
APIに料金はかからないと紹介されています。ただし、使える量に上限があり、1回の投稿で1,600ユニットを使います。
つまずき
2020年7月以降に作った確認前のプロジェクトから投稿すると、動画が非公開に制限されます。解除には監査が必要です。
個人なら、まず公開予約から始めるほうが手間は少なくて済みます。
公式ページ
GitHub Pages + 公開リポジトリ
できること
HTMLなどのファイルを置くだけで、Webページとして公開できます。
費用
公開リポジトリなら、GitHub Freeで使えます。
つまずき
非公開リポジトリにしても、サイトは公開されます。商取引が主な目的のサイトには使えません。
複数報道
GitHub Actions + 定期実行
できること
決まった時刻に、ページの作り直しを自動で実行できます。
費用
公開リポジトリの標準ランナーは、無料のままと報じられています。
つまずき
非公開リポジトリは、無料枠(Freeは月2,000分)を超えると課金されます。
AI + GitHub
できること
GitHubのリポジトリにAIをつなぐと、AIがファイルを直して「変更案(プルリクエスト)」を出します。人が確認してから反映できます。
共通
どのAIも、事前にGitHub側でつなぐ作業と、リポジトリの選択が必要です。
複数報道
ChatGPT(Codex)
できること
リポジトリをつなぎ、作業を頼むと、変更をプルリクエストにして出します。プルリクエストへの @codex 呼び出しにも対応と報じられています。
つまずき
利用にはChatGPTの有料プランが必要と報じられています。
公式ページ
Gemini(Jules・Code Assist)
できること
Julesはリポジトリを読み、修正や更新をプルリクエストにします(Google公式の案内あり)。Code Assistは、プルリクエストの要約とレビューが中心です。
つまずき
ファイルを直す役はJules、見る役はCode Assist、と分かれています。企業向け版はGoogle Cloudの設定が必要です。
これから検証
Claude
できること
リポジトリをつなぐと、ファイルを直して反映まで行います。週1の定期実行にも使えます。
つまずき
僕が試せる範囲の確認です。公式ページでの確認はこれからです。
ほかのAIは未確認です。確認できたら、ここに足します。
料金や制限は変わります。使う前に、各サービスの公式ページで確認してください。
