# AIマップ

組織に属さない人(個人事業主・小さなお店・ひとり仕事の人)にも、大きな組織で働く人と同じように「周りがどのAI・Webサービスをどう使っているか」が見えるようにするための、学びのためのページです。

## 方針

- 載せるのは、広く使われている主要なサービスだけです。
- 情報には確度ラベルを付けます(公式ページ / 複数報道 / 単独報道 / 未確認)。
- 料金や機能は変わります。各サービスの公式ページで確認してください。
- 特定のサービスへ誘導する場所ではありません。

## 構成(予定)

- `data/` 週次の更新データ(表示と分けて保存)
- `docs/` 公開するページ(GitHub Pages)
